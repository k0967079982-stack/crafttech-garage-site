## 1. 品牌定位與核心賣點

- **產業類別**：汽車維修店（技術型診斷與精修中心）
- **主要客群與場景**：面臨「汽車故障維修」需求的一般車主與反覆亮故障燈之車輛
- **解決的核心痛點**：**汽車故障缺乏維修技術**（包括傳統保養廠只看故障碼盲目換零件，以及車主因缺乏專業知識而無法判斷報價合理性）

## 4. 本機預覽方式

因瀏覽器對部分功能（如剪貼簿 API、相對路徑資源載入）在 `http://localhost` 下支援最完整，建議使用本機靜態伺服器預覽：

- **方式一（Python 3）**：
  ```powershell
  python -m http.server 8080
  ```
  開啟瀏覽器前往 `http://localhost:8080`
- **方式二（Node.js `npx serve`）**：
  ```powershell
  npx serve . -l 8080
  ```
- **方式三（VS Code Live Server）**：於 `index.html` 點擊右鍵選擇 **Open with Live Server**。

## 5. 功能驗收與測試步驟

### A. 限時活動「進行中」與「已過期」驗收
1. **進行中狀態**：直接開啟首頁，確認頂部橫幅顯示倒數「天、時、分、秒」持續跳動，且可點擊「複製優惠碼」自動複製 `TECHFIX10` 並套用至預購清單。
2. **已過期狀態（快速測試法）**：在網址列加上查詢參數 `?promoTest=ended`（例如 `http://localhost:8080/?promoTest=ended`）並重新整理，即可驗收活動結束文字顯示、倒數區塊與優惠碼按鈕隱藏、以及預購單無法再套用過期優惠碼的行為。
3. **實測過期時間**：亦可暫時將 `js/data.js` 中的 `PROMO_CONFIG.endTimeISO` 改為過去時間（例如 `"2025-01-01T00:00:00+08:00"`）確認實際時間到期行為，測試完成後再改回。

### B. 預購清單與明細輸出測試步驟
1. 在型錄區點擊任兩項商品的「加入預購」，觀察導覽列購物車數字即時更新。
2. 重新整理頁面，確認已選商品與數量仍透過 `localStorage` 保留。
3. 試著將「聯絡人暱稱」留空並點擊「複製明細」，確認出現友善錯誤提示並將焦點導回暱稱欄位。
4. 填入暱稱與車款故障備註，確認右側明細預覽同步更新；點擊「複製明細」與「下載 `.txt`」，驗證剪貼簿文字與下載的 `crafttech-preorder-summary.txt` 內容完整。

### GitHub 上傳前檢查項目
- **無敏感資料**：專案無 `.env`、無 API 金鑰、無任何真實個人資料或後端設定。

- **建議提交範圍**：確認僅提交 `AGENTS.md`、`README.md`、`.gitignore`、`vercel.json`、`index.html`、`css/style.css`、`js/data.js`、`js/app.js` 與 `images/` 內所有圖片檔。

### Vercel 部署操作（原生靜態網站可直接部署）
本網站為純原生 HTML/CSS/JS，**完全不需要建置步驟（Build Step）即可直接部署於 Vercel**：
1. 登入 Vercel 後點選 **Add New... → Project**，從 GitHub 匯入本專案儲存庫。
2. **Framework Preset** 選擇 **Other**。
3. **Root Directory** 確認維持 `./`（即包含 `index.html` 的專案根目錄）。
4. **Build and Output Settings** 保持預設留空（不需填寫 Build Command 與 Output Directory），點擊 **Deploy**。

#### Vercel 介面需確認項目清單
- [ ] Framework Preset 為 `Other`
- [ ] Root Directory 指向包含 `index.html` 的根目錄
- [ ] 環境變數（Environment Variables）維持空白（本專案無金鑰）
- [ ] 部署完成後開啟正式網址，確認圖片、CSS 與 JS 皆回傳 HTTP 200（無 404）

#### 關於 `vercel.json` 自訂快取說明
本專案已附帶 `vercel.json`，原因在於網站包含較多本地圖片與靜態資源，透過自訂 HTTP `Cache-Control` 標頭可提升回訪載入速度並保留檔案更新彈性：
- `/images/(.*)`：設定 `public, max-age=604800, stale-while-revalidate=86400`（圖片快取 7 天，避免重複下載）。
- `/(css|js)/(.*)`：設定 `public, max-age=3600, must-revalidate`（樣式與腳本快取 1 小時並於過期後驗證，確保更新商品資料或活動時間能即時生效）。

## 7. 部署後人工驗收測試步驟

1. **手機導覽測試**：將瀏覽器切換至手機寬度（如 `375px`），點擊右上角「選單」確認可展開；點擊任一連結或按 `Esc` 確認可正常收合。
2. **商品搜尋與分類測試**：同時選擇「電腦診斷檢測」與搜尋「示波器」，確認只顯示符合項；輸入無關字詞（如 `xyz`）確認顯示查無結果畫面並可點「顯示全部 15 項商品」復原。
3. **商品詳情彈窗測試**：點擊任一卡片「查看詳情」開啟彈窗，依序測試「點背景遮罩關閉」、「按鍵盤 `Esc` 關閉」，確認關閉後焦點回到原按鈕。
4. **預購明細測試**：加入商品、套用優惠碼 `TECHFIX10`、填寫暱稱與車況備註，測試數量加減、重整保留、`複製明細` 與 `下載 .txt`。
5. **社群分享預覽測試**：將部署後的正式網址貼入 LINE 聊天室、Facebook Sharing Debugger 或 Open Graph 預覽工具，確認標題、描述與 `images/hero-garage.jpg` 縮圖正確顯示（提醒：部分社群爬蟲要求 `og:image` 為完整 `https://` 網址，正式上線後可於 `index.html` 將 `og:image` 補上完整網域前綴）。
